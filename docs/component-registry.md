# Component registry

Search here before creating a component. Add a row for every exported UI component.

| Component | Layer / slice | Purpose | Props (short) | Used by |
|---|---|---|---|---|
| FactValue | entities/fact | `render(value)` with its SourceCitation; the `Fact<T>` type makes a value without a source impossible. Wrapper has `data-citation` (AC-3). `compact` (table cells): the value and a verification dot (ok/warn), the citation in a Disclosure; the status in words is in the toggle name | `fact`, `render`, `onOpenCitation?`, `now?`, `compact?`, `align?` | features, widgets, app |
| SourceCitation | entities/fact | Domain and page, verification in words, "Demo data", freshness; with a document and `onOpen` a button (`{ documentId, page, quote }`), else a link (`target="_blank"`, `rel="noopener noreferrer"`); quote in a Disclosure | `provenance`, `variant?` (`chip`, `inline`), `onOpen?`, `now?` | features, widgets, app |
| SafetyBadge | entities/institution | Institution kind with icon and words (`INSTITUTION_KIND_LABEL`, the same words for filters); explanation in a Disclosure. Texts in `model/safety-texts.ts` are a DRAFT pending legal approval; no insurance claims | `kind`, `partners?` (fintech, resolved by the caller) | features, widgets, app |
| CompatibilityBadge | entities/rule | Eligibility with icon and headline; reasons from the trace via `explainEligibility` (rule label, or a sentence with formatted values) | `result: EligibilityResult`, `compact?` (reasons in a Disclosure) | features, widgets, app |
| Disclosure | shared/ui/disclosure | `<details>` toggle with a panel: Escape closes and refocuses; absolute from `sm`, in the flow on phones. Not inside `<p>` | `summary`, `label` (screen readers), `children`, `align?` (panel from the right edge), `icon?` (the ⓘ mark) | RateValue, SourceCitation, badges |
| ExplainMath | shared/ui/explain-math | Engine steps (`<ol>`, formula in `<code>`, inputs in `<dl>`, none when empty) and assumptions; "Edit" names the assumption. Engine texts shown as is. Section has `data-assumption` (AC-3) | `steps`, `assumptions`, `onEditAssumption?`, `title?`, `headingLevel?` (2–4) | result widgets |
| RateValue | shared/ui/rate-value | Formats a `Rate` or `SignedRate` (minus U+2212); with `explain` a Disclosure. Not inside `<p>`: `<details>` is not phrasing content | `rate`, `explain?`, `explainLabel?` | everywhere; a bank's rate goes through FactValue |
| MetricCard | shared/ui/metric-card | Labelled group with value, hint, tone. `warn`/`danger` require `toneLabel` (type), so colour is never the only signal | `label`, `value` (already formatted, never a number), `hint?`, `tone?`, `toneLabel` | widgets |
| FreshnessLabel | shared/ui/freshness | `<time dateTime>`: "Updated today/yesterday/N days ago" on the UTC calendar; future date shows the absolute date; "may be outdated" past `staleAfterDays` | `at`, `now`, `staleAfterDays?` (no default: product rule) | everywhere. On SSG pages render it on the client with `shared/lib/clock`, else "N days ago" freezes at build time |
| BulletChart | shared/ui/charts | Server-rendered SVG bar (aria-hidden) with a marker line and bands; visible text carries value, marker and ranges; past the axis the bar stops at the edge and `overflowText` is shown. `percent` may start below zero (`min`), so a negative metric draws left of zero. Numbers for geometry only in `scale.ts` (ADR-013, lint rule) | `label`, `kind` (`usd` with Cents, `rate` with Rate, or `percent` with a number), `max`, `min` (percent), `value`, `marker?`, `bands?`, `overflowText?` | widgets (coverage-planner, bank-health) |
| DataTable | shared/ui/data-table | Native table: sort (header button, `aria-sort`, none → asc → desc), hidden columns, row expansion (`aria-expanded`, `aria-controls`, full-width row), first column sticky; no vertical scroll box (E5): the region scrolls sideways below xl, and from xl (the widest table fits) it stops clipping and the header sticks to the page; focusable scroll region; states loading, empty, error. Ties ordered by row id | `caption` (required), `columns: Column<T>[]` (`id`, `header`, `cell`, `compare?`, `align?`), `rows`, `getRowId`, `status`, `error`, `onRetry`, `emptyTitle`, `defaultSort`, `sort` + `onSortChange`, `sortDisabled?` (headers disabled until hydration), `hiddenColumnIds`, `renderExpanded` + `expandLabel`, `expandedIds` + `onExpandedChange` | comparison widgets. Text comparators use a fixed locale: `a.localeCompare(b, 'en-US')` |
| DemoDataBanner | shared/ui/demo-banner | DEMO DATA notice, not dismissable (AC-5) | none | app/layout |
| Skeleton, EmptyState, ErrorState | shared/ui/states | Loading, empty and error states; retry only for a retryable `GatewayError` | `label`, `className`; `title`, `children`; `error`, `title`, `onRetry` | everywhere |
| MoneyInput, PercentInput | shared/ui/inputs | Text field parsed on blur into `Cents` or `Rate`, error by `MoneyParseError` code | `label`, `hint`, `name?` (lets a form focus the field), `defaultValue`, `allowNegative` (money), `onValueChange` | features, widgets |
| StateSelect | shared/ui/inputs | Native select of 50 states and DC (`shared/config` `US_STATES`) | `label`, `value` (code or `''`), `name?`, `onChange` | features, widgets |
| ProfileForm | features/edit-profile | The only profile writer: fields (text on blur, selects on change), store notices (load error, not saved, reset), export, import (16 KiB, checked before reading; over a non-empty profile asks first), erase; questions in the page (internal `InlineConfirm`), not `confirm()`. Disabled and `aria-busy` until hydrated. Load with `import()` only | `focusField` (`ProfileFormField` or null) | widgets/profile-drawer |
| ProfileDrawer, ProfileDrawerFallback | widgets/profile-drawer | Header button with the profile summary, never income ("No profile yet", "Profile: 2 of 4 filled", "Profile: NY · complete") and a native modal `<dialog>` on `?profile=<field>`; the form loads on the first opening (`next/dynamic`, `ssr: false`). Escape closes, focus returns. Inside `<Suspense>` | none | app/layout |
| FilterForm | features/filter-products | Compare filters written straight to the URL: search (debounced by its parser), terms present in the catalog, institution type (`INSTITUTION_KIND_LABEL`), minimum APY, maximum to open, "hide products I can't open" (needs a profile), Reset. Reads the URL: inside `<Suspense>` | `terms`, `withProfile` | widgets/compare-table |
| SponsoredSlot | widgets/sponsored-slot | Labeled ad slot (ADR-006), async server component: items loaded at build (`loadSponsored`, `'use cache'`), nothing runs in the browser. "Sponsored · advertiser" in words, disclosure, link `rel="sponsored noopener noreferrer"`. Renders nothing without items. Mount only in `app/**`, outside tables and lists (AC-6) | `placement` | app/compare (`compare_top`), app/product (`product_aside`) |
| ProductBreakdown | widgets/product-breakdown | One product: terms through FactValue, after-tax steps (`useProductMath`), full CompatibilityBadge, SafetyBadge and a link to the bank. Assumptions open the profile drawer (`edit-assumptions`); citations write `?doc=&page=&q=` (`useOpenCitation`). Data from `loadProductData` (`'use cache'`) | `ProductData` | app/product |
| BankSearch | widgets/bank-search | Institution list: name, SafetyBadge, product count, best APY through FactValue. Search and kind filter in memory, URL keys `bank` and `bankKind` | `items`, `dataset` from `loadBankList` | app/banks |
| BankHealth | widgets/bank-health | Call-report metrics against the fact's own market median and mean (`percent` BulletChart, including negative), "n/a" when a metric is absent, total assets via `formatUsdFromThousands`, balance-sheet shares as text, products linking to `/product/[id]` | `BankDetail` from `loadBank` | app/banks/[id] |
| AccountRows | features/plan-coverage | Account rows (bank, single/joint, amount). Add focuses the new bank field; Remove returns focus to Add. Not stored (ADR-004) | `rows`, `institutions`, `onAdd`, `onRemove`, `onChange`, `takeFocus` | widgets/coverage-planner |
| CoveragePlanner | widgets/coverage-planner | Limit from InsuranceRules through FactValue (unverified, said in words), the account form, per-bank BulletChart of amount against the category limit, insured and not-insured totals, ExplainMath and engine warnings. DRAFT insurance wording | `institutions`, `rules` from `loadCoverageData` | app/tools/fdic-coverage |
| YieldComparator | widgets/yield-comparator | Best eligible CD, savings and Treasury after tax (`useNetYield` per category). Without a profile, a prompt that opens the drawer. The scenario is edited from an assumption | `products`, `taxTables` from `loadYieldData` | app/tools/after-tax-yield |
| Landing | widgets/landing | Home: the value, three entries (compare, coverage, after-tax yield), "How we make money" linking to /disclosure. That block is a DRAFT | none | app/page |
| SiteFooter | widgets/site-footer | Footer: links to /methodology, /disclosure, /privacy; the demo-data notice (`DEMO_DATA_TEXT`, same words as the banner) and the privacy line; the data set date. Async server component, date loaded at build (`loadDataset`, `'use cache'`) | none | app/layout |

## Modules (slices without UI yet)

Every slice gets a row here when it is created (spec §2, slice rule 4).

| Module | Layer / slice | Purpose | Public API | Used by |
|---|---|---|---|---|
| institution queries | entities/institution | Institutions and bank metrics | `institutionsQuery`, `institutionQuery`, `bankMetricsQuery` | widgets, app |
| product queries | entities/product | Products by category, one product | `productsQuery`, `productQuery` | widgets, app |
| eligibility explanation | entities/rule | Trace → `{ status, headline, reasons }`; values formatted by field (cents as dollars, codes as words from `@fa/contracts` labels) | internal (`model/explain-eligibility.ts`), used by CompatibilityBadge | entities/rule |
| fact queries | entities/fact | Facts, the source registry, the data set date; `freshnessNow(datasetInfo)` gives `now` for freshness labels (data set `asOf` for mock data, the clock otherwise) | `factsQuery`, `sourcesQuery`, `datasetInfoQuery`, `freshnessNow` | widgets, app |
| CompareTable | widgets/compare-table | DataTable of a category, data loaded at build (`loadCompareData`, `'use cache'`, tax tables for `TAX_YEAR`) and passed as props, so the table is in the static HTML and the client never queries. URL filters and `?sort=` applied in memory after hydration. Default order computed by the widget (`defaultOrder`): top APY without a profile, `rankProducts` with one, said in words above the table; DataTable gets ordered rows and `sort={null}`. With a profile: Net interest and Net yield (`data-assumption`), Fit (`CompatibilityBadge compact`). Filter form above (`FilterForm`; disabled `FilterFormStatic` in the static HTML, no layout shift). Expanded row (`RowDetails`): `SafetyBadge` with partners, full `CompatibilityBadge`, `ExplainMath` with engine and profile-default assumptions. Empty states: no match (how to get products back); "N products need more data" (`NeedsDataNote`, buttons open the drawer on each missing field, `needsData` maps rule fields to form fields). The ad slot sits in page.tsx above it | `category`, `products`, `institutions`, `dataset`, `taxTables` (from `loadCompareData(category)`) | app/compare |
| product filters | features/filter-products | URL filter state (nuqs) and in-memory filtering | `useProductFilters`, `filterProducts`, `PRODUCT_FILTER_KEYS` | widgets |
| document queries | entities/document | Document metadata | `documentQuery` | widgets, app |
| reference queries | entities/reference | Tax tables, insurance rules | `taxTablesQuery`, `insuranceRulesQuery` | widgets, app |
| sponsored queries | entities/sponsored | Ads per placement (ADR-006) | `sponsoredQuery` | widgets/sponsored-slot |
| profile store | entities/profile | Draft in this browser only, versioned, export/import | `useProfileDraft`, `useCompleteProfile`, `useProfileStatus`, `useProfileHydrated`, `useProfileActions` (edit-profile only), `rehydrateProfile`, `exportProfile`, `parseImport`, `MAX_IMPORT_BYTES`, `DEFAULT_SCENARIO`, `REQUIRED_FIELDS`, `missingFields`, `PROFILE_PRIVACY_TEXT` (DRAFT, one copy for the drawer, erase and /privacy) | features, widgets, app/providers |
| headlineApy | entities/product | Highest tier APY (via `compareRate`) | `headlineApy(product)` | filter-products, sorting |
| product filters | features/filter-products | URL filters (nuqs), pure `filterProducts`, `filterRanked` | `PRODUCT_FILTER_KEYS` (parsers and filters join with the UI in E4) | app |
| citation URL state | features/open-citation | `?doc=&page=&q=`, history push. The viewer that reads it is E6 | `CITATION_KEYS`, `useOpenCitation` (`{ current, open, close }`) | widgets/product-breakdown, app |
| edit assumptions | features/edit-assumptions | Maps an assumption id to a profile field and opens the drawer. Writes nothing | `assumptionField`, `useEditAssumptions`. `default_scenario` → `principal`, `city_marginal_rate` → `cityMarginalRate`; the tax year is not editable | widgets/product-breakdown, widgets/yield-comparator |
| product math | features/compute-net-yield | `useProductMath`: one product's eligibility and `computeNetYield`. Null on the server. `useNetYield` stays the list ranker and is null without a complete profile | `useProductMath` | widgets/product-breakdown |
| plan coverage | features/plan-coverage | `usePlanCoverage`: row state and `planCoverage` (engine loaded on the first row). Selected fintechs stay in the candidate list so the engine can exclude them; other fintechs are left out | `usePlanCoverage` | widgets/coverage-planner |
| bank search URL | widgets/bank-search | `?bank=&bankKind=` | `BANK_SEARCH_KEYS` | app/url-keys |
| profile drawer URL state | entities/profile | `?profile=<field>`: a field name, never a value (ADR-004); open pushes, close steps back over our entry (`history.back()`) or replaces when the drawer arrived open (link, reload) | `useProfileDrawer` (`{ field, open, close }`), `PROFILE_DRAWER_KEY`, `PROFILE_FORM_FIELDS`, `ProfileFormField` | widgets/profile-drawer; edit-assumptions (step 3) |
| net yield | features/compute-net-yield | `useNetYield(products, profile, tables)`: `rankProducts` in the browser, `useDeferredValue` on the profile, memo on the three inputs; null without a complete profile | `useNetYield` | widgets/compare-table |
| table sort URL state | features/filter-products | `?sort=<SortKey>.<asc\|desc>`; `effectiveSort` gives null (default order) for no sort or a column not shown, URL untouched | `useProductSort`, `effectiveSort`, `PRODUCT_SORT_KEY`, `ProductSort`, `SortKey` | widgets/compare-table |
| query client | shared/lib | Freshness, retry policy, client per request | `getQueryClient`, `makeQueryClient`, `STALE_TIME` | app/providers, entities |
| clock | shared/lib | The only wall clock in apps/web | `now`, `today`, `setClock` | client code |
